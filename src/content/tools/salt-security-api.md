Salt Security aborda el problema fundamental de la seguridad API: no puedes proteger lo que no sabes que existe. Su motor de descubrimiento continuo analiza el tráfico de red para identificar todas las APIs —incluyendo shadow APIs y zombies que el equipo de desarrollo desconoce— y construye un inventario actualizado automáticamente.

El motor de detección de comportamiento aprende el patrón normal de cada API y detecta desviaciones sutiles que indican ataques, como un atacante iterando sobre IDs para explotar un BOLA (Broken Object Level Authorization) o extrayendo datos lentamente para evadir límites de rate.
