Secret Server descubre las cuentas privilegiadas del entorno —administradores locales y de dominio, cuentas de servicio, credenciales de red y de base de datos—, las incorpora a una bóveda cifrada y aplica políticas de acceso con aprobación, motivo justificado y caducidad.

La rotación automática de contraseñas cierra el problema de fondo: las credenciales privilegiadas dejan de ser conocidas por las personas y de permanecer inalteradas durante años. Las sesiones iniciadas desde la bóveda se pueden lanzar sin mostrar la contraseña, grabar íntegramente y cortar en caliente si se detecta algo anómalo.

Para el lado no humano, que hoy es el más numeroso, ofrece gestión de secretos para aplicaciones, guiones y tuberías de despliegue mediante API y bibliotecas, sustituyendo las contraseñas incrustadas en ficheros de configuración, que siguen siendo una de las causas más frecuentes de compromiso.
