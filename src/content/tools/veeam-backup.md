Veeam Backup & Replication es la plataforma de protección de datos más desplegada del mundo para entornos virtualizados. Su motor de backup image-level para VMware vSphere y Microsoft Hyper-V permite recuperaciones instantáneas de VMs, archivos individuales y objetos de aplicaciones como SQL Server, Oracle y SAP HANA.

La característica de inmutabilidad (Veeam Hardened Repository) garantiza que los backups no puedan ser modificados ni eliminados, incluso si un atacante obtiene credenciales de administrador, cumpliendo con los requisitos de recuperación ante ransomware.

Para cumplimiento, Veeam ofrece verificación automatizada de backups (SureBackup), informes de cumplimiento para GDPR, SOC y normativas sectoriales, y retención a largo plazo con capacidades de archivado en cloud y tape.
