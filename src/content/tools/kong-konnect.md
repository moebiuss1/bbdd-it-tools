Kong Konnect gestiona de forma centralizada las instancias de Kong Gateway
desplegadas en cualquier nube o entorno on-premise.

- **Kong Gateway**: proxy de APIs de alto rendimiento, open source (Apache 2.0), base de todo el ecosistema Kong
- **Konnect**: plano de control SaaS con gestión multi-región, políticas centralizadas y analítica de tráfico
- **Kong AI Gateway**: control de acceso, rate-limiting y observabilidad específicos para tráfico hacia proveedores de LLM
- Listado en el registro CSA STAR además de SOC 2 Tipo II e ISO 27001 sobre la plataforma Konnect
- Soporte para FIPS 140-2 en Kong Gateway para entornos regulados
